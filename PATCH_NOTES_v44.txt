Zach's Ultimate Buffet — v44 Admin Console Overhaul

ADMIN PANEL
- Rebuilt the panel as a two-column developer console with keyboard selection and direct mouse clicks.
- Added 16 admin actions:
  1. Restore full health
  2. Add one maximum heart
  3. Add five maximum hearts
  4. Grant one random upgrade
  5. Grant three random upgrades
  6. Choose a specific upgrade by number, key, or exact name
  7. Unlock all currently missing upgrades
  8. Double the current damage multiplier
  9. Become invulnerable for 15 seconds
  10. Clear all enemy bullets
  11. Skip the current boss
  12. Jump to any boss by name or number (can start a run from the panel)
  13. Defeat the current boss instantly, bypassing Last Stand
  14. Restore the current boss's health and reset its attack state
  15. Reset player and teammate ability cooldowns
  16. Boost movement speed and fire rate for 15 seconds
- Host-only checks prevent co-op guests from changing the authoritative shared simulation.
- The admin panel can be closed with Escape or its Back to Settings button.

SECRET-BOSS HINTS
- Added spoiler-light lore clues for The Hollow King, Chronos, Leviathan Prime, The Crimson Emperor, The False Hero, and The Forgotten Creator.
- Included the in-game relic clue: defeating bosses without taking a hit can award fragments; collecting three unlocks the Relic Hunter achievement.

TESTING
- JavaScript syntax and archive integrity checks were run on the packaged game.
- A real browser-based two-device multiplayer playtest was not available in this environment.

NOTE
- The admin code is a client-side convenience gate, not secure authentication. Anyone with the downloadable game source can inspect it.
